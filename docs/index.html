coordinatex

Small, strongly-typed geospatial primitives for Go backend services. Standard library only.

API reference GitHub 

go get github.com/bakhod1r/coordinatex

Quick start

tashkent := coordinatex.MustNew(41.2995, 69.2401)
samarkand := coordinatex.MustNew(39.6542, 66.9597)

d := coordinatex.DistanceBetween(tashkent, samarkand)
fmt.Println(d, coordinatex.Direction(tashkent, samarkand)) // 266.xx km SW

if coordinatex.WithinRadius(user, shop, 5*coordinatex.Kilometer) {
    // shop is within 5 km
}

What's inside

Distance

Haversine, equirectangular, Vincenty on WGS84 (inverse and direct), distance matrix.

Direction

Initial/final bearing, 4/8/16-point compass, destination, midpoint, interpolation.

Bounds and proximity

Handles antimeridian crossings. Radius search, nearest-N, grid spatial index, DBSCAN.

Grids

Geohash, UTM, MGRS, Plus Codes, Web Mercator XYZ tiles and quadkeys.

Geometry

Polygons with holes, spherical containment, convex hull, polylines, simplification, circles.

Geofencing

Circle, polygon, rectangle and corridor fences. Enter/exit detection, distance to fence.

GPS tracks

Speed, spike filter, Kalman smoothing, stop and trip detection, GPX/KML.

Serialization

JSON, text, DMS/DM, GeoJSON features, Google encoded polylines, WKT/EWKB, sql.Scanner.
